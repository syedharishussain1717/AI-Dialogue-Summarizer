# 📝 Dialogue Summarizer

A simple AI-powered text summarization web application built with **Python, Hugging Face Transformers, and Streamlit**.

The project uses a fine-tuned **DistilGPT2** model trained on the **SAMSum dialogue summarization dataset** to generate summaries from conversations.

## 🚀 Features

* Enter a conversation/dialogue
* Generate an AI-based summary
* Fine-tuned DistilGPT2 model
* Model hosted on Hugging Face
* Simple Streamlit web interface

## 🛠️ Technologies

* Python
* Hugging Face Transformers
* DistilGPT2
* SAMSum Dataset
* PyTorch
* Streamlit

## ▶️ Run Locally

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
